# 0008: Repository name and home

* **Status:** accepted
* **Date:** 2026/10/10
* **Decided by:** Iosef Tesla R. [Ignatz-CastroR]

## Context

The project needs a name readable by two audiences: Genoese Italian speakers and associations, and the wider developer community, recruiters included. It also needs a home: a personal account, or a neutral organization that associations could co-own.

## Decision

* **Name: `ligurian-keyboard`.** "Keyboard" is understood by everyone; "IME" is jargon.
* **Home:** the maintainer's public GitHub account, `Ignatz-CastroR`. Contributors of good will are welcome.
* **Discoverability for Italian speakers** comes from the bilingual description, the Italian section that opens `README.md`, and the topics: `ligure` `genovese` `zeneize` `lingua-ligure` `tastiera` `grafia-oficia` `ligurian` `input-method` `typescript`.
* Genoese associations will be contacted and invited to take part.

## Consequences

* If an association later wants the repository under its own organization, GitHub's transfer keeps every commit attributed to its author and redirects the old address.
