Tastiera ligure per Android

Scrivi senza accenti in qualsiasi app: WhatsApp, Gmail, Facebook. La barra dei suggerimenti propone la parola in grafîa ofiçiâ.

1. Tastiera ligurian_keyboard.kmp 2. Dizionario ignatzcastror.lij.ligurian_keyboard.model.kmp

Installazione

  1. Installa l'app gratuita Keyman di SIL: keyman.com/android.
  2. Scarica i due pacchetti qui sopra, la tastiera e il dizionario.
  3. In Keyman apri il menu, poi Settings, Install Keyboard or Dictionary, Install from local file. Scegli ligurian_keyboard.kmp nella cartella Download e tocca Install.
  4. Ripeti il punto 3 con ignatzcastror.lij.ligurian_keyboard.model.kmp.
  5. Per usarla in tutte le app: in Keyman, menu, Get Started, Enable Keyman as system-wide keyboard, e attiva Keyman. Poi, in qualsiasi app, cambia tastiera con l'icona della tastiera in basso.

Se Keyman è in italiano, le voci dei menu sono tradotte.

Come si usa

  1. Non serve mai scrivere gli accenti. Scrivi zeneize: la barra propone zenéize; tocca il suggerimento. Scrivi zena: propone Zêna.
  2. Dopo un apostrofo la parola ricomincia: scrivi d'aegua e, dopo d', la barra propone ægua.
  3. Solo se vuoi: tenendo premuta una vocale ottieni le lettere accentate, la a anche æ, la c ç, la n ñ.
  4. Due tocchi su Maiusc bloccano le maiuscole.

Il dizionario cresce ogni giorno: per le parole nuove, scaricalo e installalo di nuovo.

Ligurian keyboard for Android

Type plain letters in any app: WhatsApp, Gmail, Facebook. The suggestion bar offers the word in grafîa ofiçiâ.

Installation

  1. Install the free Keyman app by SIL: keyman.com/android.
  2. Download the two packages above: the keyboard [1] and the dictionary [2].
  3. In Keyman, open the menu, then Settings, Install Keyboard or Dictionary, Install from local file. Pick ligurian_keyboard.kmp in the Download folder and tap Install.
  4. Repeat step 3 with ignatzcastror.lij.ligurian_keyboard.model.kmp.
  5. To use it in every app: in Keyman, menu, Get Started, Enable Keyman as system-wide keyboard, and turn Keyman on. Then switch keyboards in any app with the keyboard icon at the bottom.

How to use it

  1. You never need to type accents. Type zeneize: the bar offers zenéize; tap it. Type zena: it offers Zêna.
  2. After an apostrophe the word starts again: type d'aegua and, after d', the bar offers ægua.
  3. Only if you wish: hold a vowel for the accented letters, a also for æ, c for ç, n for ñ.
  4. A double tap on Shift locks capitals.

The dictionary grows every day: download and install it again to get the new words.

Teclado ligur para Android

Escribe sin acentos en cualquier aplicación: WhatsApp, Gmail, Facebook. La barra de sugerencias propone la palabra en grafîa ofiçiâ.

Instalación

  1. Instala la aplicación gratuita Keyman de SIL: keyman.com/android.
  2. Descarga los dos paquetes de arriba: el teclado [1] y el diccionario [2].
  3. En Keyman abre el menú, luego Settings, Install Keyboard or Dictionary, Install from local file. Elige ligurian_keyboard.kmp en la carpeta Download y toca Install.
  4. Repite el paso 3 con ignatzcastror.lij.ligurian_keyboard.model.kmp.
  5. Para usarlo en todas las aplicaciones: en Keyman, menú, Get Started, Enable Keyman as system-wide keyboard, y activa Keyman. Después, en cualquier aplicación, cambia de teclado con el icono del teclado en la parte inferior.

Si Keyman está en español, los nombres de los menús aparecen traducidos.

Cómo se usa

  1. Nunca hace falta escribir los acentos. Escribe zeneize: la barra propone zenéize; toca la sugerencia. Escribe zena: propone Zêna.
  2. Después de un apóstrofo la palabra empieza de nuevo: escribe d'aegua y, después de d', la barra propone ægua.
  3. Solo si quieres: mantén pulsada una vocal para las letras acentuadas, la a también para æ, la c para ç, la n para ñ.
  4. Dos toques en Mayús bloquean las mayúsculas.

El diccionario crece cada día: para tener las palabras nuevas, descárgalo e instálalo de nuevo.
