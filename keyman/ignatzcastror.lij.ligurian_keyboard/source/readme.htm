Dizionario ligure [grafîa ofiçiâ]

I suggerimenti della tastiera ligure: scrivi una parola senza accenti e il dizionario la propone in grafîa ofiçiâ. Contiene le forme zeneize approvate nel dizionario del progetto; la versione del pacchetto è la data del dizionario.

Serve anche la tastiera, il pacchetto ligurian_keyboard.kmp.

English

The suggestions of the Ligurian keyboard: type a word in plain letters and the dictionary offers it in grafîa ofiçiâ. It holds the approved zeneize forms of the project's dictionary; the package version is the dictionary's date.

The keyboard is needed too: the package ligurian_keyboard.kmp.
