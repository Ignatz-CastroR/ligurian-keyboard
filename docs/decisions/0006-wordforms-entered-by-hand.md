# 0006: Every wordform is entered by hand; no morphology generator yet

* **Status:** accepted
* **Date:** 2026/10/10
* **Decided by:** Iosef Tesla R. [Ignatz-CastroR]

## Context

A keyboard needs every *wordform* a person may type: plurals, feminines, every verb form. A list of lemmas alone misses most real text. The forms can either be entered by contributors, or generated by a morphology engine, which is a serious linguistic project in its own right.

## Decision

* For now, contributors enter **every wordform**: the base form and each inflected form, one row each.
* **No morphology generator** for now. It may become part of the mature project.
* The base form is created automatically from the headword: see [0014](0014-automatic-base-form.md).

## Consequences

* Coverage grows only as fast as contributors add forms.
* Each extra form needs its own review, which keeps quality high.
